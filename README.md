# ConvertAndCalc

A lightweight static calculator and conversion website.

## Deploy on Vercel
1. Upload these files to a GitHub repository.
2. In Vercel, create a new project and import the repository.
3. Framework Preset: Other.
4. Build Command: leave blank.
5. Output Directory: leave blank.
6. Deploy.

Then add `convertandcalc.com` under Project Settings → Domains and follow Vercel's DNS instructions.
